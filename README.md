# RINGSPOTTER｜摔角捉迷藏

一隻為 iPhone 直向畫面而設的原創街機風隱藏角色遊戲。玩家會走過四個摔角主題舞台：AEW、STARDOM、CMLL，以及新日本（NJPW），每站要在限時內找出三位指定角色。

Arcade Edition 採用黑金／霓虹舞台、CRT 掃描線、金屬計分板、硬邊摔角手造型、掃描準星及命中／失誤特效，保留單手觸控操作。

## 玩法

- 點按畫面中的指定摔角手。
- 點錯會扣 2 秒；每站有 2 次提示，每次扣 250 分。
- 完成四站後會顯示世界巡迴總分及本機最高分。
- 鍵盤支援：`H` 提示、`P` 暫停、`R` 重開、`F` 全螢幕。

## 本機執行

任何靜態 HTTP server 都可使用，例如：

```bash
python3 -m http.server 4173
```

然後開啟 `http://localhost:4173/`。
